# Personal Site
This is a mostly static website.
I original had it as a node.js website, as that is what was required by my hosting service.
But now it is using github actions to just serve the public page as a website.

# Actions
The github actions public the public folder as the root folder, for the website.

# Troubleshooting
I encountered issues trying to set up the domain name.
After that, it reverted back to just uploading my website under public folder, instead of using the actions to public the /public folder as the root folder.
